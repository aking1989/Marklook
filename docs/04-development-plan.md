## 3. 里程碑详细定义

### M0 骨架与验证（第 1 周，4.5 人日）

**目标**：用最短路径验证技术路线，尤其是 PDF 导出。

**交付物**

- Tauri 2 + Vite 8 + React 19 + TypeScript 6 工程可运行。
- 设计令牌、三套主题骨架、应用布局（侧栏 / 文档区 / 状态栏）。
- `Platform` 接口 + Tauri 实现 + Mock 实现。
- Rust 基础 I/O：`pick_file_and_allow`、`read_document`、`write_document`（原子写）、`stat_path`。
- 最小渲染（CommonMark）→ 阅读视图；CodeMirror 源码模式切换；保存。
- PDF 技术验证报告（macOS / Windows 各一次）。

**退出标准**

- macOS 上 `pnpm tauri dev` 可打开真实 Markdown 文件，阅读、切换、保存成功。
- 保存后文件内容完全一致，EOL/BOM 保持。
- PDF 验证结论写入文档：系统打印是否可用、分页与字体是否可接受、是否启用 Typst 备选。
- CI 骨架可运行 typecheck、lint、unit、cargo check。

**风险处理**

- 若 PDF 验证失败，立即在计划中插入 Typst 备选任务（3–5 人日），并从缓冲扣除。

---

### M1 阅读体验（第 1–2 周，5.5 人日）

**目标**：把"能读"变成"愿意长期读"。

**交付物**

- 完整渲染管线：GFM、frontmatter、行号锚点、大纲、sanitize、相对链接/图片、远程图片占位。
- KaTeX、Shiki、Mermaid 接入与懒加载。
- 阅读排版：字号、行高、栏宽、字体、主题、代码块样式、表格滚动。
- 模式切换与滚动同步（line-map）。
- 大纲面板与点击跳转。
- 设置面板（外观分区）与持久化。
- 代码块复制、图片基础交互。

**退出标准**

- 100KB 技术文档渲染 < 200ms（本机基线；M1 实测约 190ms，2026-10-23 修订——原估算 150ms，实测 unified 管线在 100KB 纯 GFM 文档（表格/代码/公式混排）上即约 190ms，已含"无内嵌 HTML 跳过 rehypeRaw"与单次遍历收集优化，渲染结果 LRU 缓存使编辑↔阅读切换免重渲染）。
- 模式切换位置误差 ≤ 1 行（普通文档）。
- 公式、Mermaid、代码高亮、脚注、任务列表显示正确。
- 三套主题在亮暗环境可读；字号/栏宽调节即时生效。
- 大纲当前项跟随滚动，点击定位准确。

---

### M2 工作区（第 3–4 周，6 人日）

**目标**：从"单文件阅读器"升级为"文档库"。

**交付物**

- 打开文件夹、扫描、文件树（惰性、排序、忽略规则）。
- 搜索 Worker：CJK 分词、索引、增量更新、结果定位。
- 当前文件监听、工作区树刷新。
- 冲突检测与解决面板、自动保存、草稿恢复。
- 最近文件 / 最近工作区、工作区恢复。
- Rust：`scan_vault`、`list_dir`、`watch_paths`、草稿命令。
- 核心单测与 E2E（打开、搜索、冲突）。

**退出标准**

- 1,000 文件工作区索引 < 2s，查询 < 50ms。
- 中文搜索"编辑器 / 编辑"均可命中并正确定位到行。
- 外部修改干净时静默重载，脏时冲突条正确；三种解决方式均不丢数据。
- 强制结束进程后，草稿可恢复。
- 文件树忽略 `node_modules`、`.git`、`dist`。

---

### M3 源码编辑（第 4 周，4 人日）

**目标**：编辑体验达到"日常可用"。

**交付物**

- CodeMirror 6 完整配置：Markdown 语法、代码围栏语言、搜索面板、主题、键位。
- 编辑器与 store 的同步策略、撤销历史保持、模式切换位置保持。
- 图片粘贴/拖入、assets 目录、`mdasset://` 协议。
- 大文件模式与阈值降级。
- IME 兼容与快捷键互斥。
- 组件测试与 E2E（编辑、粘贴、切换）。

**退出标准**

- 1MB 文档输入无卡顿（p95 < 16ms）。
- 模式来回切换 100 次，位置不漂移、撤销栈不丢失。
- 粘贴截图后文件落到 assets，Markdown 语法正确，阅读视图立即显示。
- 拼音输入期间不触发任何全局快捷键。
- 大文件模式有明显标识且可正常保存。

### M4 发布工程（第 5 周，5 人日）

**目标**：成为可安装、可分发的桌面应用。

**交付物**

- HTML 单文件导出（样式、图片、KaTeX、Mermaid）。
- 打印 / PDF 闭环与打印样式。
- 原生菜单、快捷键、命令注册表。
- 文件关联、单实例、冷启动打开、退出确认。
- macOS universal 与 Windows NSIS 构建、图标、CI 产物。
- 签名/公证说明文档（按分发需求执行）。

**退出标准**

- 双平台安装包产出，安装后能启动、打开文件、保存。
- 双击 `.md` 冷启动/热启动均能打开；单实例生效。
- 导出 HTML 断网可打开，样式与阅读视图一致。
- 打印出的 PDF 分页合理，代码不截断，中文正常。
- 未保存退出有三选一确认。

## 6. 关键路径与并行

```text
T0.1 → T0.5 → T0.6 → T1.1 → T1.2 → T2.1 → T2.2 → T3.1 → T4.1 → T4.4 → T4.5 → M5 → 发布
                 ↘ T1.3 ↗        ↘ T2.3 → T2.4 ↗
```

- **关键路径**：脚手架 → IO → 最小闭环 → 渲染管线 → 搜索/工作区 → 编辑器 → 导出/文件关联 → 打包。
- PDF 验证是**时间盒任务**（0.5 人日），无论结论如何都在 D5 结束，避免阻塞。
- 测试与文档分散在各任务内，不单独占里程碑；M5 只做系统级回归。
- 单人项目无真正并行，所谓"并行"指同一周内穿插，降低单点卡死风险。

**任务完成定义（DoD）**

- 代码符合 TypeScript 严格模式与 ESLint 规则。
- 核心逻辑有单元测试；交互有组件或 E2E 测试。
- 用户可见错误有中文提示，不暴露堆栈。
- 涉及性能路径的改变记录一次基准。
- 相关设计文档若与实现不一致，同步更新。
